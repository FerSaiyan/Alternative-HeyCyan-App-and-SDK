# Design System Draft

## Direction
Minimal, airy, and premium with soft gradients and frosted-glass surfaces.

## Visual tokens
- Primaria / Deep teal: `#1f5b66`
- Fundo / Off-white: `#fafaf7`
- Secundaria / Sage green: `#95b6a5`
- Accent / Champagne: `#cdbe98`
- Text / Graffiti: `#24393f`

## Typography
- Primary: Plus Jakarta Sans
- Monospace accents: IBM Plex Mono

## Components
- Glass card for key content groups.
- Rounded full buttons for primary CTAs.
- Compact pill tags for section markers.

## Motion
- Keep motion subtle (hover lift, fade-in, slight scale).
- Avoid fast or bouncy animations in medical context.

## Social proof imagery
- Best crop/canvas for carousel before/after pairs: 4:5 portrait, 1080x1350 px recommended.
- Before and after images for the same client must use the same crop/canvas size and subject alignment.
- Export WebP or high-quality JPEG in sRGB, keep important subject details inside center safe area.
- If a source image is landscape or very tall, place it on the 4:5 canvas with off-white/champagne background rather than stretching it.
