# Pharmacy Network Draft

## Objective
Offer optional partner pharmacy path for patients with valid prescription outcomes.

## MVP data model
- Pharmacy profile
- Service area and SLAs
- Order handoff status
- Fulfillment updates

## Workflow
1. Prescription outcome confirmed.
2. Patient chooses partner or external pharmacy.
3. If partner selected, handoff order intent.
4. Track fulfillment milestones for patient transparency.

## Risks to manage
- Out-of-stock events
- Delayed fulfillment
- Incomplete status sync
