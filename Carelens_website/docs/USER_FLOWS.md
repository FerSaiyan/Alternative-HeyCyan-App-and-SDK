# User Flows

## Consumer flow
1. Visit landing page.
2. Read process, founder message, and refund conditions.
3. Complete short onboarding.
4. Pay monthly subscription (BRL 1700).
5. Schedule medical appointment.
6. Receive consultation outcome.
7. If prescribed, may buy via partner pharmacy.
8. If not prescribed or buying elsewhere, request refund under policy.

## Doctor partner flow
1. Receive scheduled appointment context.
2. Conduct consultation independently.
3. Register clinical decision and optional prescription.
4. Record notes needed for operational follow-up.

## Pharmacy partner flow
1. Receive validated prescription handoff.
2. Confirm order and fulfillment status.
3. Send status updates to patient operations timeline.

## Admin flow
1. Monitor payment events.
2. Ensure scheduling completion after purchase.
3. Reconcile consultation outcomes.
4. Handle and audit refund requests.
